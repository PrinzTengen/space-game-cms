# UI-Kit: Space Game Website

Klickbare Nachbildung der aktiven Richtung **F2 Orbit** (`Space Game - Richtung F2 Orbit.dc.html`).
Inhalte und Zustände kommen aus `content.js` (Kopie aus dem Projekt-Root, DE/EN).

Screens
- **Start** – Vollbild-Hero mit Key-Art, Planetenrand, Galaxy-CTA; drei Säulen; neueste Beiträge; CTA-Bildpanel.
- **Logbuch** – Seitentitel, Filter-Segment mit Zählern, Kartenraster.
- **Beitrag** – Artikel-Fenster, Kopfbild 21:9, Fließtext 19/1.7, „Nächster Beitrag“.
- **Download** – Stepper, Discord-Anmeldung (Lade-Zustand), Plattformwahl, Datei-Readout, Download → Erfolgsmeldung.
- **System & FAQ** – Anforderungstabelle, Akkordeon.

Dateien: `Shell.jsx` (Header, Footer, PageWrap), `Home.jsx`, `Logbook.jsx`, `Article.jsx`, `Download.jsx`, `Faq.jsx`, `App.jsx`.
Beitragsbilder sind Platzhalter – im Original sind es leere Bild-Slots.
