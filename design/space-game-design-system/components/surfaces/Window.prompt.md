HUD window — the default container for every content block (pillars, panels, cards, article).

```jsx
<Window as="section" padding="lg">
  <h2>Mit Discord anmelden</h2>
</Window>
<Window interactive padding="sm">…Bildkarte…</Window>
```

- Nie border-radius, nie Schatten. Eckwinkel immer in --sg-accent.
- `solid` für Inhalte über unruhigen Bildern.
